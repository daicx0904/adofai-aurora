# Aurora v0.1.6

从 v0.1.6 起，ADOFAI Mod Manager（AMM）更名为 **Aurora**，以避免与另一个同名工具混淆。本次更新还修复了两处 Mod 更新检查问题。

## 更名说明

Aurora 仍然是《冰与火之舞》的多来源 Mod 管理器，原有功能和使用方式保持不变。

- 原有设置、收藏和日志会保留。
- GitHub 旧地址会自动重定向到新地址。
- 安装版可以直接覆盖安装，绿色版可以解压覆盖原目录。

## 问题修复

### 年份和周数格式的版本号漏报更新

部分 Mod 使用 `26w40c` 这样的版本号。此前只比较第一段数字，导致 `26w40c` 和 `26w42a` 被视为同一版本，无法提示更新。

现在会逐段比较其中的数字和字母，能够识别 `26w42a` 比 `26w40c` 更新。`2.4.1` 等常见版本号的比较方式保持不变。

### 手动检查更新仍使用缓存

此前短时间内再次点击“检查全部更新”，可能直接使用缓存结果，无法及时发现刚发布的更新。

现在“检查全部更新”和单个 Mod 的“检查更新”都会刷新相关数据。启动时的自动检查仍使用缓存，减少重复请求。

## 升级方式

使用 v0.1.2 或更高版本的用户，可以在软件内点击“立即更新”。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.6.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录 |

原有设置和收藏会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
