# Aurora v0.1.6

本版起，项目由「ADOFAI Mod Manager（AMM）」更名为 **Aurora**，并修复了两个更新检查的问题。

## 更名为 Aurora

为避免与另一个同名工具混淆，本版起使用新名称 **Aurora**，定位不变：

> **多来源 · 中文优先 · 默认来源在国内可直接访问。**

改名对使用没有影响：

- 设置、收藏、日志都会保留；
- GitHub 旧地址会自动重定向到新地址；
- 安装版直接覆盖安装即可；绿色版解压覆盖原目录即可。

## 修复

### 「年份+周」写法的版本号会漏报更新

有些 Mod 用「年份+周+修订字母」这种版本号（例如 `26w40c`）。此前这类版本号只比较第一段数字，
`26w40c` 与 `26w42a` 会被当成同一个版本，作者更新了也不会提示。

现在这类写法会按「数字/字母片段」逐段比较，能正确判断 `26w42a` 比 `26w40c` 新；
其它常见写法（如 `2.4.1`）的判断方式保持不变。

### 第二次点「检查全部更新」可能没有真正联网

此前短时间内重复点击「检查全部更新」时，界面会立刻显示“检查完成”，
看起来像没检查——实际是命中了缓存（站点列表、来源列表、详情等）。

现在**手动检查**（「检查全部更新」和单条「检查更新」）会**强制刷新**，确保拿到最新结果；
启动时的自动检查仍使用缓存，不打扰、也不浪费流量。

## 升级方式

| 版本 | 做法 |
| --- | --- |
| 安装版 | 软件内点「立即更新」，或运行 `Aurora-Setup-0.1.6.exe` 覆盖安装 |
| 绿色版 | 软件内点「立即更新」（自动替换并重启），或解压 zip 覆盖原目录 |

> 原有设置、收藏都会保留。保险起见，升级前可以顺手备份游戏目录里的 `Mods` 文件夹。
