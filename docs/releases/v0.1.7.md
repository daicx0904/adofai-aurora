# Aurora v0.1.7

本次更新加入了新的 Mod 来源，并改进了在线 Mod 列表和详情的加载方式，同时修复了滚动崩溃、来源切换、图标显示和更新提示等问题。

## 新增 Mod 来源：modrift

在线 Mod 来源列表新增 **modrift**，位于 ADOFAI Tools 之后。

- 无需登录或 API key，国内可以直接访问；
- 支持查看 Mod 介绍和版本，并选择版本安装；
- 会根据当前游戏版本选择合适的文件；
- 对于没有可下载文件的版本会自动跳过，避免下载到空内容。

## 在线 Mod 加载改进

### 打开页面时先显示已有内容

打开或切换到之前浏览过的来源时，Aurora 会先显示上次加载的列表，再在后台刷新。刷新失败时，已经显示的内容仍会保留，并提供重试入口，不需要一直等待空白页面。

### 显示加载进度

列表加载过程中会显示当前进度，例如：

```text
ADOFAITools 共 125 个资源，已加载 60 / 125（后台补全中…）
```

首屏内容出现后，其余分页会在后台继续加载，滚动到列表底部时会继续显示后续内容。

### Mod 详情也会缓存

查看过的 Mod 详情会保存在本地。再次打开时会先显示缓存内容，随后在后台刷新；没有缓存时会显示加载状态。

## 问题修复

### 修复链接上的鼠标滚轮导致崩溃

鼠标停留在 Mod 介绍中的链接上滚动时，程序此前可能抛出异常并崩溃。现在已修复。

### 切换来源时不会被旧请求覆盖

在一个来源仍处于加载状态时切换到其他来源，旧请求完成后可能会把界面切回之前的来源。现在切换来源会取消上一次请求，并丢弃其结果。

### 修复应用图标显示问题

修复了图标外圈出现白色光晕，以及图标尺寸比其他程序略小的问题。桌面上已有的快捷方式可能仍使用旧图标，删除后重新创建即可刷新。

### 缩短第三方来源的等待时间

TUF、modlist 等第三方来源的请求超时时间从 60 秒调整为 30 秒。请求失败时会更快显示提示，并回退到已有缓存。

### 更早显示 Aurora 自身更新提示

启动时现在会优先检查 Aurora 自身更新，再检查已安装 Mod 的更新。这样 Aurora 有新版本时，提示会更早出现。

### 避免误识别同名工具

更新检查不再把名称为 `AMM` 或以 `AMM` 开头的其他工具当作 Aurora，只会识别明确属于本项目的名称和标识。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以在软件内点击“立即更新”。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.7.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录 |

### v0.1.5 及更早版本

v0.1.5 及更早版本的自动更新程序存在问题，无法可靠升级到新版本，请手动升级：

- 安装版：运行 `Aurora-Setup-0.1.7.exe` 覆盖安装；
- 绿色版：将 v0.1.7 ZIP 解压并覆盖原来的程序目录。

原有设置、收藏和日志会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
