# Aurora v0.1.8

本版更新了内置的 UnityModManager，改进了首次使用向导和日志系统，并修复了 modrift 上部分资源点开报错的问题。

## 内置 UnityModManager 更新

内置内核从 0.32.5 更新到 **0.33.2**，与上游新版保持一致。首次使用向导里安装内置内核时，用的就是这个版本。

## 首次使用向导

装加载器这一步现在会**自动对比**「ADOFAITools 上的最新版本」和「Aurora 内置版本」，直接告诉你用哪个：

- 站点有更新版本 → 推荐从站点获取；
- 版本相同、内置更新、站点没有或连不上 → 推荐使用内置内核（不用下载，也不受网络影响）；
- 第 2 步没有填写 API key → 不查询站点，直接推荐内置内核。

推荐的那个按钮会高亮显示，并在下面写明理由（例如“两边都是 0.33.2，推荐用内置内核”）。另外，站点版本比内置旧时，按钮不再写“获取最新”——那样点下去其实是降级。

## 日志与反馈

- **日志默认开启**，不用再设置环境变量。遇到问题后直接从软件里导出日志即可反馈。
- 每份日志都有大小上限（2 MB，超出后自动轮转并保留上一份），磁盘占用有限。
- 写入前会**脱敏**：API key、下载签名、token 等都会替换成 `***`。
- 崩溃日志（`crash.log`）现在会带上版本、系统和安装形态，方便定位问题。
- 「设置 → 关于」新增「诊断与反馈」：
  - **打开日志文件夹**；
  - **导出诊断包**：把日志、环境信息和设置（已脱敏）打包成一个 zip；
  - **反馈问题**：直接打开反馈页面。
- 日志默认开启，也可以在「设置 → 关于」里关闭（关闭后只保留崩溃日志）。

## 来源标注

在线 Mod 页面现在会标注当前来源并附上链接：

- ADOFAI Tools、modlist、modrift：标注对应站点；
- **TUF**：标注「Mod 数据与推荐由 TUF（The Universal Forums）提供」，并回链到 TUF 站点。

## 问题修复

### modrift 上部分资源点开报 404

modrift 上不只有 Mod，还有资源包、预设、着色器、插件等类型。此前 Aurora 一律按 Mod 去请求，遇到非 Mod 条目（例如 Nexus's Keyviewer）会提示“站点上没有找到这个资源（404）”。

现在会按条目的真实类型请求。不是 UnityModManager Mod 的资源会明确提示“这是资源包/预设，不是 UMM Mod”，并引导到原站页面手动下载，不再显示无效的安装按钮。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以在软件内点击“立即更新”。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.8.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
