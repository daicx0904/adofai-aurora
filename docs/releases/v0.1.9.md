# Aurora v0.1.9

本次更新重点改进了 Mod 安装与卸载的安全性，修复了更新检查中的若干问题，并让 Mod 简介支持 Markdown 排版。**由于此前某些异常的 Mod 包可能导致文件被写入游戏目录之外，建议所有用户更新。**

## 安装与卸载安全性改进

### 拒绝包含异常 Id 的 Mod 包

部分 Mod 包中的 `Info.json` 可能包含不合法的 Id（例如 `..`），此前这类数据可能导致文件被写入 `Mods` 目录之外，极端情况下甚至会影响游戏目录中的其他文件。

现在，Aurora 会拒绝安装包含此类异常 Id 的 Mod 包，避免文件被写入预期目录之外。

### 安装失败时保留原有版本

此前安装 Mod 时，如果压缩包损坏、文件被占用等情况导致安装中断，可能留下不完整的 Mod 文件，甚至影响已经安装的旧版本。

现在，Aurora 会先将整个 Mod 包解压到临时目录，确认准备完成后再替换旧版本。即使安装失败，原有版本也不会受到影响。

### 游戏运行时禁止修改 Mod 和加载器

游戏运行期间，相关文件可能正被占用，导致安装、卸载或修改操作失败；部分改动还可能在游戏退出时被覆盖。

现在，游戏运行时不允许安装、卸载、启用或禁用 Mod，也不允许部署或卸载加载器。执行这些操作前，请先关闭游戏。

### 自动恢复中断的安装

如果安装过程中遇到强制关闭程序或断电等情况，可能会遗留临时文件或旧版本备份。

现在，Aurora 会在下次启动时清理残留的临时文件，并在发现旧版本备份时自动恢复原有文件，降低安装中断造成的数据丢失风险。

### 卸载加载器时保留其他工具的文件

电脑上可能同时安装 BepInEx 等其他加载器，它们也可能使用 `winhttp.dll`、`doorstop_config.ini` 等文件。此前卸载加载器时，存在误删其他工具文件的风险。

现在，Aurora 只会删除能够确认由自身写入的文件。对于其他文件，会予以保留，并在操作结果中说明。

## 更新检查改进

本次更新修复了多个可能导致更新漏报、误报或检查效率下降的问题。

- **修复更新提示误报版本号规则不同的问题**：修正了参数传递错误，避免资源站的更新提示全部显示「版本号规则不同」。
- **避免分页异常导致无限请求**：当资源站忽略分页参数时，更新检查不再无限重复请求。
- **减少网络异常时的等待时间**：网络不可用时，「检查全部」不再为每个 Mod 分别等待一次超时。
- **修复多 Mod 仓库的版本号误判**：当 `Repository.json` 中列出多个 Mod 时，不再错误地使用其他 Mod 的版本号进行比较。
- **统一仓库地址与版本比较规则**：仓库地址只会移除末尾的 `.git`；GitHub 更新检查也改用与其他来源一致的版本比较规则。
- **修复版本号显示错误**：修正 `1.0.0.5` 被显示为 `1.0.5` 的问题。
- **保留手动设置的更新源与游戏目录**：从资源站重新安装 Mod 时，不再覆盖手动绑定的更新源；启动时也不会仅因自动检测评分更高，就擅自更改用户手动选择的游戏目录。

## 界面与性能改进

### 修复 Mod 详情页的显示错乱

此前，在 Mod 详情页加载图标期间切换到其他 Mod，旧 Mod 的版本列表可能覆盖新 Mod 的内容。

现在，详情页会正确处理不同 Mod 之间的加载状态，避免旧请求的结果影响当前显示。

### 修复在线列表中的安装状态

已卸载的 Mod 此前可能仍在在线列表中显示「已安装」。现在，列表会正确反映 Mod 的安装状态。

### 减少列表刷新开销

在线 Mod 列表在后台加载后续分页时，此前每补充一页都会重新刷新整个列表。

现在，后台补页时只会加载新增条目的图标，减少不必要的重复操作。

### 改进更新按钮与失败提示

在「已安装」页面中，连续点击更新按钮此前可能重复触发操作；检查更新失败时，也可能没有任何提示。

现在，重复点击不会再次触发同一操作，检查失败时会明确显示提示信息。

### 图标下载失败后自动重试

图标下载失败后，Aurora 现在会在 3 分钟内自动重试，无需重启软件即可等待重新加载。

### 缓存游戏版本信息

读取游戏版本时，现在会使用缓存，避免每次刷新列表都重复读取数 MB 的文件，减少不必要的 I/O 操作。

### 提高配置与记录写入的可靠性

配置、收藏、安装记录和更新源现在均采用原子写入，降低写入过程中断导致文件损坏的风险。

当配置文件损坏时，Aurora 会先将其备份为 `settings.json.broken`，再使用默认配置启动，避免直接覆盖损坏文件而丢失排查线索。

### 改进界面异常处理

界面线程中未处理的异常，此前可能直接导致程序闪退。

现在，Aurora 会记录异常日志并弹窗提示，尽可能让程序继续运行。遇到此类异常后，仍建议重启软件，以确保状态恢复正常。

## Mod 简介支持 Markdown

在线 Mod 的简介和各版本更新说明现在支持 Markdown 排版，可以更清晰地展示以下内容：

- 标题与加粗文本；
- 有序列表与无序列表；
- 代码与引用；
- 表格、链接和图片。

排版所使用的字体、字号和行距与界面其他文字保持一致。

对于超长说明，Aurora 会自动截断；对于使用纯 HTML 编写的说明，则会回退为原文显示，避免内容直接变成空白。

## 升级方式

**建议所有用户尽快升级至 v0.1.9**，以避免旧版本中 Mod 安装过程可能导致的文件写入风险。

使用 v0.1.6 或更高版本的用户，可以在软件内点击「立即更新」。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.9.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本自带的自动更新存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
