# Aurora v0.1.6.1

修复一个会导致程序直接退出的问题。

## 修复

### 鼠标停在链接上滚动会让程序崩溃

在“设置”等页面，把鼠标指针放在链接上（例如“来源”里的 TUF、modlist 网址）滚动滚轮时，
程序可能直接退出，日志里会出现：

```text
System.InvalidOperationException: “System.Windows.Documents.Run”不是 Visual 或 Visual3D。
```

原因是平滑滚动在查找界面元素时，遇到链接内部的文本元素会抛出异常。
本版已修正，并让滚轮处理不会再因为意外而中断程序。

## 升级方式

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.6.1.exe` 覆盖安装，或在软件内点“立即更新” |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录，或在软件内点“立即更新” |

原有设置和收藏会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
