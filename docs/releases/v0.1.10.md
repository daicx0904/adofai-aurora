# Aurora v0.1.10

本次更新修复了内置 UMM 内核更新不提示的问题，并调整了 Mod 更新方式，减少更新时丢失配置和预设的情况。

## 内核更新检查

v0.1.8 起，Aurora 内置的 UnityModManager 内核已升级至 0.33.2，但此前更新检查只比较资源站提供的版本与游戏中已部署的版本。如果资源站版本较旧，即使 Aurora 已内置更新的内核，也不会提示。

现在会同时比较资源站版本和内置版本，选择较新的一个：

- 内置内核比已部署版本更新时，“UMM 环境”页面会显示两个版本号，并提示前往“安装 / 修复加载器 → 使用内置内核”。
- 点击“检查内核更新”时，即使未填写 API key 或无法连接资源站，也可以根据内置版本判断是否需要更新。
- 使用内置内核更新时，直接从本地部署，无需下载。

## Mod 更新改为覆盖安装

此前更新 Mod 时会替换整个旧文件夹，仅单独保留 `Settings.xml`，可能导致 Mod 存放在自身目录中的其他配置、预设或文件丢失。

现在更新时会保留旧目录内容，再用新版本覆盖：

- 新包中没有的文件会保留，包括用户配置、预设和子目录中的文件。
- 新包中的同名文件会覆盖旧文件。
- 安装失败时仍可回滚。

> 覆盖安装也会留下新版安装包中已不再包含的旧文件。此外，如果新包包含同名配置文件，该文件仍会被覆盖。更新前建议备份重要配置。

## 升级方式

使用 v0.1.6 或更高版本的用户，可以在软件内点击“立即更新”。也可以退出软件后手动升级：

| 版本 | 操作 |
| --- | --- |
| 安装版 | 运行 `Aurora-Setup-0.1.10.exe`，覆盖安装 |
| 绿色版 | 将 ZIP 解压并覆盖到原来的程序目录 |

> v0.1.5 及更早版本的自动更新存在问题，请手动下载安装包覆盖安装，或解压 ZIP 覆盖原程序目录。

原有设置、收藏和日志会保留。升级前建议备份游戏目录中的 `Mods` 文件夹。
